A `machine.Disk` took open files, and each caller read the chain itself: `cmd/spin-machine/chain.go` from the qcow2 headers, the boot tests by hand, and spin's runner through `qemu-img info --backing-chain` under Landlock, refusing an image outside the disk's own. `machine.OpenDisk(DiskPath)` now opens the top read-write unless the disk is read-only and every image below it read-only. It reads the chain from the headers and refuses a backing file that is not a regular file under the caller's `Under` (files or directories), symbolic links resolved. A writable top that is one of `Under`'s images, the shared base, is refused (rule 1). Each backing file is opened `O_PATH`, checked through its descriptor and reopened through it, so no rename falls between the check and what QEMU is handed. A FIFO is never opened to find out what it is. A chain that comes back on itself, a missing backing format, an encrypted image, an external data file, a backing name over QEMU's 1023 bytes and a header that claims more than its first cluster are refused, each naming the file. `Image.Size` carries the size the guest sees, which spin bounds QEMU's writes by. `spin-machine --disk` takes the release's base as `Under` unless `--disk-under` names others, and `lab compat` names the previous release's. *Header parser vs qemu-img, measured* (laptop under load, one chain of overlay, overlay and the release's base): `qemu-img info -U --backing-chain` 3.4 ms p50 over 50 runs, `OpenDisk` 0.045-0.050 ms, the reader it replaces 0.015 ms. *Landlock:* not needed in process. It confined qemu-img's C parser to the images it was given. This reader executes nothing, opens nothing before checking it, and bounds every read by the first cluster (at most 2 MiB). *Goal numbers:* not run on the bench. The 0.03 ms the checks add to a boot's or a restore's disk open is under the ±7-9 ms a 20-boot interval resolves. boot:record passes on a tree of v20261121.01 with this spin-machine, its root disk now opened by `OpenDisk`. *Status:* in place. spin adopts it in place of `backingChain`, passing its disk's images other than the top as `Under`.
