*Why:* a machine with a TPM cost the cold first login +36 ms (#719), and a workspace that runs shirudo pays it; where it went was not measured (#745). *Measured* on the bench, spin's shape, v20261126.01's parts, tpm-crb against no TPM: the cold first login +31.7 [+22.0, +36.0], sshd accepting +30.1, accept to login +0.8 within noise, 30 a side (lab 45829973230); restored +6.3 [+5.3, +7.0] evicted, `running` +6.4, 30 a side (lab 45829981897). Attributed: QEMU's start to the guest's first instruction +4.8 [+4.1, +9.7], swtpm's start and QEMU's backend waiting on it (ledger, 3 a side, lab 45830006273); the kernel's initcalls +19.1 [+17.3, +21.5], all of it `crb_acpi_driver_init` (10 a side, lab 45829990377), and in the ledger's kernel window 18.8 ms more idle with the kernel's CPU unchanged; after PID 1 nothing (no TPM unit on the login's chains, CPU by process within ±1 ms, lab 45829997996, 3 a side), since the image's systemd is built without TPM2. A function_graph trace of the probe (lab 45833173266, 2 boots) put 16.7 ms of it in one command: qboot leaves the TPM unstarted, so the kernel's first TPM2_SelfTest is refused (1.6 ms), it sends TPM2_Startup (1.2) and asks for the self test again, which right after a startup has libtpms test every algorithm it has, while the vCPU sleeps in 1 ms polls. *Tried*, each decided on the two goal numbers, both arms with a TPM: `CONFIG_HW_RANDOM_TPM` off, +3.0 [−3.0, +9.5] (lab 45831227791); swtpm `--flags startup-clear`, −0.1 [−6.3, +7.5] (lab 45830336920), since the kernel's first self test then pays the whole test; the first ten polls of a command 50-100 µs apart, initcalls −3.7 but the first login −1.5 [−9.4, +3.1] (labs 45832388057, 45832372721, 45832380145); all rejected. *Done:* kernel 0032 drops the self test after a TPM2_Startup the kernel sent, as a TPM tests an algorithm before its first use anyway: the first login −18.6 [−25.5, −8.7], sshd accepting −19.3, initcalls −17.7 (labs 45834343191, 45834358071), the restored login −0.3 [−1.2, +1.0] (lab 45834349809). With it a TPM costs the cold first login +9.5 [+4.5, +19.5] (lab 45834343191). boot:tpm (an RSA-3072 primary, PCR 16 and an NV index across a checkpoint) and boot:lockdown's shirudo row pass on the kernel with 0032 (laptop KVM). *Status:* the remaining ~10 ms is swtpm's start, the refused self test, the startup and the capability reads, none above the noise alone; the restore's +6 ms is swtpm's start. The first command that needs an algorithm now pays its test, after the login.
