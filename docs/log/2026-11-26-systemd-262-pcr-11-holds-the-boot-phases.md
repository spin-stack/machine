*Why:* shirudo's init warned `tpm: PCR 11 holds no phase measurement` (#773). systemd 259's `systemd-pcrphase-initrd.service` is `ConditionSecurity=measured-uki`, which reads an EFI variable only systemd-stub sets, and this machine boots PVH through qboot. In 262 the phase units are `measured-os`, and `efi_measured_os()` takes `systemd.tpm2_measured_os=1` from the kernel command line before it looks at EFI. *Done:* systemd-source moves to 262.1-1ubuntu1, from tenacious's release pocket and not tenacious-proposed's 262.2, which can be withdrawn before it migrates. It is built on resolute, where all its build-deps resolve. `Spec.cmdline` adds `systemd.tpm2_measured_os=1` for a machine with a TPM only. 262 packages the TPM2 pieces as `systemd-tpm`, which stage1 does not build, so the Dockerfile builds it from #786's second build, without the sysinit and sockets wants, and the image installs it. 0001, the drop-in change, is upstream in 262, which leaves `image/systemd` with no patch, and pack, the SBOM and codeql.yml now take an empty patch directory as a part built as upstream has it. 262 has no SysV or rc.local generator, so their masks go. boot:shirudo makes its initrd from the base image's files (#777), and checks PCR 11 and the measurement log. A `--tpm --lockdown shirudo` guest: PCR 11 `75DF9C8B…`, `enter-initrd` and `leave-initrd` in `/run/log/systemd/tpm2-measure.log`, and no warning from shirudo's init. Two image builds made the same `rootfs.qcow2`. *Measured* on the bench, spin's shape, 100 a side, against v20261126.02. The 262 arm is v20261126.02 with 262 installed over each overlay (`--systemd noop`), and that edit alone, with main's own systemd, read −3.9 [−6.8, +2.1] (lab 45862597133). Without a TPM: cold first login +3.5 [+1.0, +6.8], accept to login +5.1 [+3.7, +6.3], QEMU RSS +2.0 MiB (lab 45860427795). Five ledgers of each put it in PID 1, +2.8 ms of CPU, and root's user manager, +2.4 (lab 45864189674). With `--tpm`: +19.8 [+16.0, +25.5] and +8.0 MiB (lab 45860433504), which was `systemd-pcrlogin@.service`. 262's logind starts it at each user's first login on a measured OS, ahead of the user's runtime directory and manager, and it runs `systemd-pcrextend` from the TPM2 build. Masked, +5.0 [+0.6, +8.8] and +2.1 MiB, against +24.1 [+19.8, +28.5] and +8.0 MiB with it, in one run (lab 45862592487). *Status:* carried, with `systemd-pcrlogin@.service` masked. A machine with a TPM measures only what its initrd runs: the root file system's phase units stay unwanted. What 262's PID 1 and user manager cost is #794.
