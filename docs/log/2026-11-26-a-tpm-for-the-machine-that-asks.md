*Why:* Spinbox runs shirudo's CLI as shipped, and shirudo keeps its register in a TPM NV index and makes RSA-3072 primaries under it, so a workspace that runs it needs a TPM from its first boot; QEMU was built `--disable-tpm` (#719). *Done:* QEMU is built `--enable-tpm` with `tpm-crb` and the emulator backend in qemu/devices.mak, and the release ships `bin/swtpm`, swtpm 0.10.2 with libtpms 0.10.2 and json-glib 1.10.8 built from versions.yaml's pins on QEMU's builder and linked statically (libtool's `-all-static`; with `-static` it linked glib dynamically); the build refuses one that is not static, hardened or without `rsa-keysize-3072`, and `verify qemu` asks both binaries again. `machine.Spec.TPM` is a state directory the caller keeps, like a disk, and the binary: Start runs swtpm beside QEMU on one end of a socket pair and hands QEMU the other, so nothing is bound at a path, and swtpm ends with QEMU before `Exited` closes. The record holds `tpm-crb`, `tpm-crb-cmd` and `tpm-ppi`, so a checkpoint never resumes across a TPM and none. `task boot:tpm` (laptop KVM, a tree of v20261124.01 with main's kernel and this QEMU) found `/dev/tpm0` and `/dev/tpmrm0`, made an RSA-3072 primary, extended PCR 16 and wrote an NV index from a static Go tool in the guest (the image has no tpm2-tools); a checkpoint resumed onto an empty state directory read the same three back, a cold boot on that directory the same primary and index with PCR 16 at zero, and a machine without one had neither node. A 62 MB initrd does not hide the TPM under qboot, which puts the ACPI tables below 1 MiB (`ACPI: TPM2 0xC1943`, the initrd at `0x1c1d7000-0x1ffd7fff` at 512 MiB); at spin's 128 MiB of base memory it panics the guest unpacking it, whatever the TPM, which is spin-stack/spin#1708's to answer. *Measured* on the bench, spin's shape, 20 a side interleaved against no TPM: tpm-crb cost the cold first login +36.1 [+23.3, +41.2] ms, tpm-tis +43.7 [+33.8, +55.4] (lab 45748711725); restore-first's cold login +28.3 and +37.3, its restored login +6.0 [+4.4, +7.4] and +5.5 [+3.9, +6.6] (lab 45748711747). tpm-crb, the cheaper cold boot in both runs. Where the cold 36 ms go is #745; nothing measures the boot into the PCRs, #742. *Status:* a machine's option, off by default; spin asks for it for a workspace that runs shirudo.
